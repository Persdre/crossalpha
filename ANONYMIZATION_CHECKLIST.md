# Anonymization Checklist

Before uploading supplementary material:

- [ ] No author names, usernames, emails, or affiliations.
- [ ] No local paths such as `/Users/...`.
- [ ] No Overleaf project URLs or git remotes.
- [ ] No public GitHub/Hugging Face project account links during review.
- [ ] No API keys, `.env` files, credentials, tokens, or logs.
- [ ] No `.git`, `.DS_Store`, `__pycache__`, or notebook execution caches.
- [ ] No cloud-drive links that may track reviewer downloads.
- [ ] README uses only anonymous contact/release language.
- [ ] Code paths use environment variables.
